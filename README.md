# noisetta

I enjoy exploring how technology works through hands-on experiments, software, and open-source projects. My interests include audio, electronics, optics, embedded systems, and computing.

I'm especially drawn to understanding and modifying physical devices, with software as one of the tools that makes that possible.

## Selected Projects

- **[HiBy Mods](https://github.com/hiby-modding/hiby-mods)** — A custom firmware modification project I started for the HiBy R3 Pro II, later developed with community contributors.
- **[SpotUI](https://github.com/noisetta/spotui-hiby-r3proii)** — An experimental standalone streaming client for the HiBy R3 Pro II.
- **[Auris](https://github.com/noisetta/auris)** — A Linux tool for analyzing audio libraries, spectral content, and signal levels.
- **[Audio HUD](https://github.com/noisetta/audio-hud)** — A KDE Plasma widget for viewing PipeWire stream and output information.
- **[Nikon Pull](https://github.com/noisetta/Nikon-Pull)** — An experimental Android tool for transferring media from compatible Nikon cameras over Wi-Fi.
